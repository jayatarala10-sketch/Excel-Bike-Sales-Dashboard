# Excel Bike Sales Dashboard

## Project Overview
This project analyzes a dataset of 1,000 potential bike buyers to identify patterns in purchasing behavior. I transformed raw data into a fully interactive dashboard that allows stakeholders to filter data by region, education, and marital status.

## Dashboard Preview
![Bike Sales Dashboard](Excel_Bike_Sales_Dashboard.png)

## Key Technical Steps:
* **Data Cleaning:** Removed duplicates, standardized "Marital Status" (M/S to Married/Single) and "Gender" (M/F to Male/Female) using Find & Replace.
* **Feature Engineering:** Created a **Nested IF Statement** to categorize ages into "Adolescent," "Middle Age," and "Old" brackets for better visualization.
* **Pivot Tables & Charts:** Built multiple pivot tables to analyze average income per purchase and commute distance impact.
* **Interactive Elements:** Implemented **Slicers** to allow dynamic filtering across all dashboard visualizations.

## Key Insights:
* **Middle Age Peak:** Customers between 31 and 54 are the most likely to purchase a bike.
* **Commute Impact:** People with shorter commutes (0-1 miles) show a higher tendency to buy bikes compared to those commuting long distances.
* **Income Factor:** On average, males who purchased bikes had a higher income than those who did not.

## Tools Used
* **Microsoft Excel** (Pivot Tables, Slicers, Nested IF Logic, Data Cleaning)
